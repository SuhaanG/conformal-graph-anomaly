# Follow-up experiment protocol

Specified before inspecting follow-up outcomes. Existing manuscript and results remain frozen.

1. Headline robustness: Amazon and Tolokers; PyGOD DOMINANT, fixed positive degree, and attribute-only Isolation Forest. Ten training seeds (0--9), five independently randomized test splits, 200 calibration draws per comparison. All runs retained. Model hyperparameters fixed independently of FDP.
2. Primary evaluation: untrimmed, label-stratified 25% test sample preserving each dataset's class prevalence to rounding. Calibration uses known normals outside the test set. No test labels enter the partially observed exposure filters.
3. Primary filters: oracle zero anomalous neighbors; zero observed anomalous neighbors with 25% or 50% of non-test nodes' labels revealed. Each filter is compared to uniformly sampled non-test normals at identical sample size and test identities. Budget n=min(1000, filtered pool size); also n=min(200, filtered pool size). Empty/too-small pools are explicitly reported, not dropped silently. This is a partially labeled reference-panel experiment, not an unlabeled deployment.
4. Sensitivity: untrimmed, 1%, and 5% trimming of calibration normals only, with fixed untrimmed test identities. Historical trimming of both pools and enriched anomaly prevalence is evaluated separately. No positive-exposure third arm constrains the main comparison.
5. Weighted conformal selection: implement Jin--Candes hypothesis-conditional Algorithm 2, checking against literal equations and the authors' reference code in continuous-score cases. Compare random ordinary BH, selected ordinary BH, correct weighted BH, deterministic WCS, and homogeneous-randomized WCS, plus weighted BY as a conservative comparator. Independent score simulation: 200 calibration, 400 test (360 null), theta=0 or 2, selection propensity q(1)=1,.25,.05, positive overlap. 2,000 independent repetitions; fixed seed streams and paired methods. Never claim the independent theorem holds on arbitrary graphs.
6. Independent graph experiment: explicitly specified random graph generator, factorial degree heterogeneity, anomalous connectivity, and degree-dependent scoring. Independent graph realizations are the replication unit; paired selection methods. Include an attribute-only score control and an all-null control. Report FDP, power, discoveries, and uncertainty over independent graphs.
7. Practical design comparison: evaluate a random/filtered reference mixture, fixed in advance, on held-out test splits; no tuning on test FDP. Report the complete tradeoff and do not call empirical success an FDR theorem.
8. Interpretation: real-data uncertainty is conditional on fixed benchmark graphs. Training seeds, test splits and calibration draws are separate levels, not independent graph replications. No acceptance probability is inferred from these experiments.

Runtime-driven changes, failed runs, implementation corrections, and additional analyses will be recorded explicitly. Do not substitute favorable exploratory cells for the prespecified primary comparisons.

## Dataset correction discovered before follow-up evaluation

DGL's official Amazon source explicitly marks nodes 0--3304 as unlabeled, with 7,818 verified benign and 821 fraudulent nodes. The historical loader ignored that mask and treated stored zeros as normal. Corrected primary Amazon evaluation/calibration therefore use IDs >=3305 only. Unsupervised training retains every node. Historical all-node evaluation is retained solely as a labeled provenance/bug sensitivity, never as verified-normal evidence. Source: https://www.dgl.ai/dgl_docs/_modules/dgl/data/fraud.html .

For partial-label experiments, a fixed 25% or 50% sample of non-test verified nodes is revealed. Both the filtered and random reference pools contain only revealed normal nodes, and exposure counts only revealed anomalous neighbors. Thus the label budget applies to the reference labels as well as neighbor labels. Test identities are identical across training seeds for each split, providing crossed training/test-split replication. The oracle arm alone may use test-neighbor labels.

Independent graph specification (before outcomes): 1,200 nodes, 10% anomalies, 25% stratified test sample, up to 200 calibration nodes. Lognormal degree propensity sigma=0 or 1.2; cross-class edge multiplier=1 or 4, normalized to a common approximate average degree of 12. Edge probabilities are clipped at .9 and clipping is recorded. Score is an attribute signal (Gaussian plus 4 for anomalies) plus theta times standardized log-degree, theta=0 or 2. Noise is either independent or a .5 mixture with normalized neighbor-aggregated noise. These are controlled analytic scorers, not trained GNNs. 500 independent graph draws per graph-parameter cell; four paired scorer conditions per graph. Partial reference labels cover 25% of non-test nodes. Five methods: oracle filter, matched random, half-filtered mixture, partial-label filter, matched partial-label random. Also 500 all-null independent graphs as a negative control. All 500 repetitions are retained irrespective of outcome.
